Privacy Policy & Data Governance

Transparency Disclosure & Compliance Standards

🛡️ 100% Free & Zero Monetization Guarantee

Career Learning Vault is a 100% free educational command hub built by Abhishek Gali. We have zero paid tiers, require no credit card information, run no commercial ad trackers, and never sell, lease, or monetize user data to third parties under any circumstances.

💾 What Data We Collect & How It Is Used

To deliver an authentic learning experience, the system stores strictly the following data in isolated database tables:

  • Account Credentials: Username and PBKDF2-HMAC-SHA256 salted password hash.
  • Study Focus Timer: Daily active seconds spent learning to calculate daily goal completion.
  • Practice Progress: Question accuracy, quiz attempts, and solved sandbox coding challenge IDs.
  • Custom Playlists: YouTube video URLs or playlist IDs candidates choose to add to their personal workspace.
🌐 Third-Party Embeds & Services

The web application integrates select external services to provide trilingual video lectures and high-performance fonts:

  • YouTube Embedded Players: Course lectures utilize sandboxed youtube-nocookie.com embeds. Interactions are subject to YouTube's standard terms.
  • CDNs & Fonts: Google Fonts (Inter & JetBrains Mono) and Tailwind CSS are delivered via global CDN endpoints for sub-50ms latency.
🗑️ Data Ownership & Cascading Deletion Rights

Candidates retain full ownership of their data. Account administrators can purge candidate accounts at any time via DELETE /api/admin/users/{id}, which initiates an instant cascading deletion permanently removing all sessions, focus timer logs, quiz histories, and custom playlists from the database.

🔒 Cryptographic Security & System Integrity

Security is engineered into every layer: 200,000-iteration PBKDF2 hashing with unique 16-byte salts, 15-minute brute-force login lockouts, parameterized SQL execution against injection attacks, and strict HTML escaping against cross-site scripting (XSS).
