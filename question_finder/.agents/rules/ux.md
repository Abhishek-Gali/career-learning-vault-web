# UX & Presentation Rules

- **Clear Categorization**: Every view in the Web UI and CLI must visually distinguish between `RECENT SOURCE`, `GENERATED PRACTICE`, `OLDER`, `LEGACY C01`, and `QUARANTINED` questions using color-coded badges and explicit labels.
- **Honest Metrics**: Never inflate source question counts with generated or duplicate questions. Always report separate counters.
- **Responsive & Fast**: The Web UI uses HTMX for seamless partial page swaps without heavy SPA frameworks.
- **Accessible Study**: Provide clear explanations, source citations, domain weights, and answer visibility toggles in quiz modes.
